# 视听剪辑决策手册（Harness Agent）

这是一份推理/审阅流程，不是另一个模型服务。目标是让当前对话模型依据真实证据作出可解释的编辑选择。

## 1. 从 brief 出发，不从滤镜出发

先明确：讲给谁看、希望观众记住什么、发布平台、目标时长、素材能否删改、必须保留的事实/对白、参考风格及音乐权利。用户只说“电影感”时，解释成节奏、构图、色调与声音的方向，请其选择偏纪实、温暖叙事还是快速宣传；不默认加黑边/慢动作/强转场。

## 2. 建立证据清单

1. probe素材；analyze_shots检出候选镜头和逐镜代表帧。
2. 用read_image看真实代表帧，必要时利用当前Harness的video_storyboard/video_zoom观察动作，不能用一张静帧猜运动或人物身份。
3. 读取真实转写，标注关键句、语气停顿、数字/专名和不可断开的表达。没有音频/ASR就明确缺口。
4. 逐镜记录“已看到的画面、可用源区间、技术风险、对应对白、可能叙事作用”。用户素材不足时宁可短一些，不重复填充凑时长，不编造B-roll。
5. suggest_edit只作保守草稿；它按时长/黑场规则筛候选，不会理解故事。Agent必须亲自结合证据修订。

## 3. 三种审慎编辑策略

### 访谈/知识内容

- 叙事清晰、事实完整和可听性优先；按完整句或词边界剪。
- 默认硬切，去掉多余等待但保留自然呼吸与反应。
- 不为“高级感”把两段对白交叠；目前没有独立J/L-cut工具。
- 背景音乐低音量，启用能量压低后仍需试听；源音乐/噪声也会触发压低。

### 纪实/温暖叙事

- 根据已有素材形成开场—环境—细节—收束，不强行伪造故事因果。
- 镜头长度由动作/信息决定，允许有意义的长镜头，不把所有长镜头标为坏。
- 时间/地点变化可考虑短叠化；动作连续处尽量硬切。
- natural或轻warm只是初始方向，不能宣称色彩匹配、肤色或HDR处理已经专业校准。

### 简短宣传/视觉蒙太奇

- 先选最有信息/动势的已有画面作开场，再用细节与结果收束。
- 保留画面辨识时间，不把“快”当成“好”。
- 此版本统一计划转场；大多数对白内容仍建议cut，少量全片非cut适合无对白蒙太奇。需要混合逐接点转场时明确尚未支持。
- 没有自动节拍检测/踩点，不声称镜头已对齐音乐拍点。

## 4. 结构化计划与自审

每段segments写具体reason，不用“高级”“精彩”这类空词。引用实际shot/cue时点；plan.analysis绑定本次分析报告。

先review_plan，再preview。机械告警不能替代Agent判断：黑场可能是叙事呼吸，冻结可能是照片，长镜头可能是核心表达。

自审需要回答：
- 观众在前几秒知道主题了吗？这个判断来自哪些实际画面/台词？
- 删除是否改变原意或暗示并不存在的因果？
- 每个切点是否截词、跳动作或让对白突然改变？缺少动态证据时明确待人工检查。
- 转场是否有叙事理由，还是只是装饰？是否造成原音重叠？
- 配乐是否压住人声？黑边有没有盖住主体/已有字幕？
- 片尾是否突然被截断？是否需要音画淡出？

## 5. 用户确认与交付

给出“剪辑意图、保留段、删减理由、实际片长、效果/配乐说明、告警与待确认项”。先交预览，再记录用户确认并approve，不得自批。

渲染后的解码/时长QC只证明机械完整性，不证明专业剪辑审美、事实、版权、调色或声音主观质量通过。
